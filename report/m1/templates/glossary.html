Glossary

용어 안내

readable node
에이전트가 독립적으로 읽을 수 있는 파일이나 코드 단위입니다.
query node
검색어 하나와 그 결과 묶음을 나타내는 탐색 행동입니다.
framework link
프레임워크 규칙을 알아야 이동할 수 있는 코드 사이의 연결입니다.
unreachable
현재 그래프의 검색·연결 근거만으로 도달하지 못한 읽기 대상입니다.
occurrence
query 결과가 발견된 파일, 줄, 문맥과 도착 node를 기록한 근거입니다.
token
파일을 읽거나 검색 결과를 보는 데 드는 텍스트 양의 근사 단위입니다.
