Glossary

용어 안내

각 용어가 어느 화면에서 쓰이는지와 값을 읽는 방법을 함께 적었습니다.

readable node
에이전트가 독립적으로 읽을 수 있는 파일이나 코드 단위입니다. 그래프에서 원 모양이며 크기는 read-unit token에 비례합니다.
query node
검색어 하나와 그 결과 묶음을 나타내는 탐색 행동입니다. 그래프에서 마름모 모양입니다.
framework link
프레임워크 규칙을 알아야 이동할 수 있는 코드 사이의 연결입니다. 그래프에서 점선으로 표시됩니다.
unreachable
현재 그래프의 검색·연결 근거만으로 도달하지 못한 읽기 대상입니다.
occurrence
query 결과가 발견된 파일, 줄, 문맥과 도착 node를 기록한 근거입니다. 근거 화면에서 압축 해제 후 확인합니다.
read-unit token
읽기 단위 하나를 읽는 데 드는 텍스트 양의 근사 단위입니다. 분포와 그래프 크기에 함께 쓰입니다.
query 전체 결과 수 / 노출 결과 수
검색이 찾은 전체 결과 수와 실제로 에이전트에 노출된 결과 수입니다. 둘의 차이가 생략된 결과 수입니다.
connection specificity
connection이 특정 대상을 얼마나 좁혀 가리키는지를 나타내는 값입니다.
candidate_cap_truncated
query 후보 개수 상한 때문에 결과 일부가 더 잘리기 전에 이미 제한되었는지를 나타냅니다.
duplicate_suppressed_count
같은 결과로 중복 판정되어 결과 수에서 제외된 occurrence 수입니다.
