## Observation procedures and independent oracles

**A — tiny public analyzer.** Call `GraphAnalyzer.analyze` with labeled finite nodes and raw relations. For reciprocal star with N leaves, per-leaf contribution is w/N; central in-fan N and out-fan N; weighted central in-fan N and out-fan w. PageRank with damping .85 gives source `(t+.85)/1.85`, leaf `t+.85*source/N`, `t=.15/(N+1)`. HITS follows the dominant singular vectors of the explicit star matrix: target hubs `1/sqrt(N)` and source authority 1 when N>1; a unit reciprocal pair has both scores `1/sqrt(2)`. Source normalized betweenness 1 for N>1 and leaf 0; degree source 1 and leaf 1/N. Both two/three-hop unions contain every other star node, so costs are sums of the independent NodeCost values. Representative swaps and bijective renaming compare every public node metric within absolute 1e-9. Multiplicity 87 cannot affect any value.

**F — file conversion then public analyzer.** Explicit source/file assignments and candidate lists determine shares arithmetically before conversion. Three symbols, two in B and one in C, yield 2/3 and 1/3; same-target file yields 1. Internal/self alternatives remain in denominator but emit no pair. Distinct original relations merge by maximum. Serialize and assert exact pairs, metadata shares, unique provenance indices/counts and raw detail-edge equality; then analyze converted edges to detect double allocation.

**P — producer integration.** Analyze controlled source fixtures, or build controlled framework model fixtures through existing public builders, then isolate declared relation kind and assert full `{representative}+candidates`, evidence and matching counters. Existing framework-rule IDs are retained; specificity is asserted only for surfaces with a pre-existing exact test oracle. Feed emitted relations to public analyzer; each of two distinct targets receives .5 without a profile. Additional controlled language/enrichment emitter seams supplied by main force a self representative with an external alternative and two different groups sharing the representative; inspect emitted groups then observe public fan/contributions. This controls resolver choice without expanding resolver accuracy.

**B — bottleneck reports.** Build two source evidence records in distinct files targeting the same ambiguous alternatives. Convert for file variants. Inspect serialized candidates and dependency network: independently enumerate non-self pairs, expected target set, two unique evidence records per target, exact line ranges, retained ambiguous group, absence of unresolved_boundary from ambiguity alone and repeat-run byte equality.

**R — report input partition.** Construct supported architecture/report fixtures then remove or replace exactly one policy marker. Call public report generation and assert the declared input error before returning a document. Inject modified JSON into previously generated HTML, open in fresh browser context, assert visible load error, zero node rows and absent graph. Unsupported supplied analyzer results must fail bottleneck API instead of being relabeled.

**U — current HTML user scenario.** Open independently constructed JSON fixtures in fresh Chromium contexts; choose node with existing UI controls or graph tap, inspect topology, expand disclosures, inspect visible group/contribution/multiplicity, paging and omission counters. Hostile label/path text must stay literal, `window.attack` remains unset, and request/pageerror probes remain empty. A custom-profile architecture-only cutoff fixture has 28 high neighbors, two .3 candidates and one .2 neighbor; max merge includes both .3 candidates and excludes .2 despite an overlapping .2 relation. Existing report UI bounds remain 30 neighbors plus center and 50 raw relationship groups per page.
